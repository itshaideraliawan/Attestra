# Attestra

AI that passes an audit. Attestra is Stratagix's AI governance layer: shared .NET libraries that every Stratagix product uses to call AI models safely.

Every AI call is redacted, schema-validated, versioned, audited and measured, and every AI output is a suggestion that a person approves, edits or rejects.

Status: in development, first release `v0.1.0` planned for Nov 24, 2026.
